# Samples

A few API-shaped responses from the `tiny` scenario, so you can see the data without running anything. All of it is fictional. Regenerate the full set with `tsunagu generate --scenario tiny --api data/api`.

| File | Shaped like |
|---|---|
| `brevo/emailCampaigns.json` | Brevo `GET /v3/emailCampaigns` |
| `brevo/contacts_lists.json` | Brevo `GET /v3/contacts/lists` |
| `line/insight_message_event_JP.json`, `_TW.json` | LINE `GET /v2/bot/insight/message/event` |
| `line/insight_followers_TW.json` | LINE `GET /v2/bot/insight/followers` |
| `shopify/orders.json` | Shopify Admin `GET /orders.json` |
